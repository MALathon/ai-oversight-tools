The Format We Need

Each review prompt should follow this pattern:

Prompt: "The protocol describes / addresses / documents [specific thing the IRB reviewer should check for]."

Stages: Which stages does this apply to? S1 (Discovery), S2 (Validation), S3 (Deployment), or All

Example: "The protocol documents a decommission plan describing how the AI system will be retired when the study ends." — S3
